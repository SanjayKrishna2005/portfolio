Micro-Architecture in 959 Standard Cells: Designing an Asynchronous Neuromorphic SNN on Tiny Tapeout 09

OCTOBER 2026
SkyWater 130nm (sky130_fd_sc_hd) · 1×1 Tile Area (160×100 μm) · 24 Pins · Zero DSP Multipliers

On Tiny Tapeout, you don’t get an endless sea of gates. You get a single standardized tile: approximately 1,000 standard cells and exactly 24 I/O pins (8 dedicated digital inputs ui_in, 8 dedicated outputs uo_out, and 8 bidirectional pins uio). When designing my cardiac event monitor (tt_um_snn_afib_detector), conventional machine learning approaches were dead on arrival. A single 8-bit digital multiplier consumes 150 to 220 standard cells in SkyWater 130nm, and a tiny 64-byte SRAM macro or register file consumes the entire tile by itself.

1. The Power-of-2 Integer Leaky Integrate-and-Fire Formulation

The biological Leaky Integrate-and-Fire (LIF) model defines membrane potential dynamics as continuous integration with exponential decay:

τ_m · (dV/dt) = -(V - V_rest) + R_m · I(t)

In digital silicon, evaluating exponential functions requires either lookup tables (LUTs) or iterative Taylor series expansions—both completely unaffordable. Instead, we quantized the neuron's membrane potential into a compact 4-bit unsigned register (reg [3:0] potential, bounded between 0 and 15) and replaced exponential integration with an arithmetic right-shift by 1 (potential >> 1).

In Verilog, the entire neuron compiles to: 

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        potential <= 4'd0;
        spike_out <= 1'b0;
    end else if (ena && spike_valid) begin
        if (potential >= THRESHOLD) begin
            spike_out <= 1'b1;
            potential <= 4'd0; // Instantaneous refractory reset
        end else begin
            spike_out <= 1'b0;
            // 50% passive decay via wire shift + synaptic integration:
            potential <= (potential >> 1) + (spike_in ? {1'b0, WEIGHT} : 4'd0);
        end
    end
end

Because an arithmetic right-shift in hardware is literally free (it is implemented purely via wire routing without a single logic gate), the entire neuron synthesis cost collapsed to just 24 standard cells—composed only of a 4-bit ripple adder and four D-flip-flops.

2. Temporal Recurrence from a Single 1-Bit Flip-Flop

Arrhythmias like Atrial Fibrillation are defined by high beat-to-beat variability (ΔRR) sustained across multiple cardiac cycles. A conventional Recurrent Neural Network (RNN) requires an $8 \times 8$ weight matrix (64 multiplications and 64 memory registers).

To solve this within our 1,000-cell budget, we introduced a single 1-bit cross-coupling register: spike_reg1. On every incoming beat, spike_reg1 latches the spike output of rate neuron N0 and injects it as an additional excitation into delta neuron N7 on the subsequent beat: 

// In reservoir.v:
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) spike_reg1 <= 1'b0;
    else if (ena && spike_valid) spike_reg1 <= s[0];
end

// Neuron 7 incorporates the delayed spike from Neuron 0:
lif_neuron #(.THRESHOLD(8'd2), .WEIGHT(3'd3)) n7 (
    .clk(clk), .rst_n(rst_n), .ena(ena),
    .spike_valid(spike_valid),
    .spike_in(gd[3] | spike_reg1), 
    .spike_out(s[7])
);

This single feedback wire introduces rich temporal hysteresis: when a rapid ectopic beat triggers N0, its memory is preserved into the next beat cycle, sensitizing N7 to fire if the subsequent beat exhibits high variability. A sustained arrhythmic episode creates a self-reinforcing cascade, while isolated premature contractions decay without false alarming.

3. Dual-Window Majority Voting (readout.v)

To eliminate false alarms caused by noisy electrode contacts or isolated Premature Ventricular Contractions (PVCs), the readout module implements a two-tiered coincidence detector:

  • FAST Window (8 beats): Rapid transient filter. Accumulates signed synaptic votes across 8 consecutive beats. If accum_fast > -1, asserts afib_fast = 1.
  • SLOW Window (16 beats): Sustained rhythm confirmation. Accumulates signed votes across 16 beats. If accum_slow > -2, asserts afib_slow = 1.
  • Majority Coincidence Gate: The final output alarm is gated by strict logical coincidence: afib_flag <= afib_fast & afib_slow. A transient spike burst cannot trigger the alarm unless confirmed by the 16-beat slow baseline.

Reverse Engineering a Physical ASIC Layout: Extracting Zero-Days with Graph Isomorphism and Z3 SMT Solving

SEPTEMBER 2026
Jane Street ASIC CTF · Flattened GDSII Polygons · Degree of Connectivity Index (DCI) · SMT Constraint Unrolling

Layout polygons tell no lies, but they speak in pure geometry. In the Jane Street ASIC Reverse Engineering Challenge, participants were handed an opaque, flattened GDSII database: raw 2D polygon streams across semiconductor layers (Diffusion, Polysilicon, Contacts, Metal1, Metal2). There were no schematic netlists, no standard cell boundary markers, no pin labels, and no clock tree documentation.

1. The Source-Drain Permutation Dilemma in Netlist Extraction

Decompiling geometry back into a transistor netlist is conceptually straightforward: wherever Polysilicon crosses Diffusion, a MOSFET channel exists. Contacts link diffusion regions to metal routing wires.

However, when applying standard sub-graph isomorphism algorithms (like VF2 or the Weisfeiler-Lehman kernel) to classify extracted transistor groups into standard gates (NAND, NOR, XOR, DFF), matching broke down completely. Why? In planar CMOS, MOSFET Source and Drain terminals are geometrically and physically symmetric. In an extracted netlist, the designation of which terminal is source and which is drain is completely non-deterministic.

To overcome this, we developed the Degree of Connectivity Index (DCI): a topological matrix metric invariant under source/drain permutations:

W_DCI(u, v) = ∑_{k=1}^{d} [ A^k(u, v) / (deg(u) · deg(v)) ]

Because the DCI edge-weight tensor treats the bilateral channel conductance as an unordered pair while weighting neighboring interconnect degrees, it produces an identical topological fingerprint regardless of terminal swaps. With DCI, our automated netlist classifier achieved 100% gate recovery accuracy across all standard cells in the ASIC core.

2. Recovering the 76-State Sequential Machine

Once standard cell boundaries were resolved, topological traversal isolated 76 D-type flip-flops clocked by a balanced H-tree clock network. Tracing the combinational cones of logic revealed that the hardware implemented a sequential puzzle checker for an $11 \times 11$ Star Battle grid puzzle. The state machine took a stream of serial coordinates across 122 clock cycles, sequentially verifying:

  • Exactly two stars per row.
  • Exactly two stars per column.
  • Exactly two stars per irregular 11-cell polyomino region.
  • The anti-adjacency constraint: no two stars may touch, even diagonally.

3. Unrolling 122 Clock Cycles into First-Order SMT Logic

Brute-forcing an input sequence across 76 flip-flops over 122 cycles would require exploring $2^{76 \times 122}$ states. Instead, we translated the recovered synthesizable Verilog directly into first-order propositional constraints for the Z3 SMT solver: 

from z3 import *

solver = Solver()
# Unroll 76 sequential flip-flops across 122 cycles
Q = [[Bool(f"q_{i}_cycle_{t}") for i in range(76)] for t in range(123)]
inputs = [BitVec(f"in_cycle_{t}", 8) for t in range(122)]

# Enforce combinational next-state transfer functions extracted from netlist:
for t in range(122):
    for i in range(76):
        solver.add(Q[t+1][i] == transition_logic[i](Q[t], inputs[t]))

# Initial reset state & target success assertion:
for i in range(76): solver.add(Q[0][i] == False)
solver.add(Q[122][PIN_SUCCESS] == True) # Assert VALID_OUT = 1

4. The Silicon Zero-Day

When Z3 returned SAT in under 4 seconds, we expected the model to output the canonical mathematical solution to the 11×11 Star Battle puzzle. Instead, the input vector revealed an impossible puzzle state: three stars were clustered directly adjacent to one another in the lower right quadrant.

Tracing the netlist logic on Pin 42 revealed a hardware zero-day:

The layout engineer had optimized the anti-adjacency checking cone using a tree of 2-input XOR and AND gates, but had omitted the diagonal boundary condition at index (10, 10). Under specific multi-cycle input skew, an unconstrained race condition disabled the adjacency fault latch!

The chip didn’t care about human game rules; it only cared about its physical gate equations. The SMT solver exploited this physical logic flaw, asserting SUCCESS = 1 in physical silicon using a completely invalid puzzle configuration.

Why 20 Watts of Warm Tissue Beats Megawatts of Cold Silicon

AUGUST 2026
Thermodynamics of Compute · Clock Tree Dissipation · Event-Driven Sparsity · Zero-Quiescent Silicon

Every computer we build is held hostage by a relentless metronome: the synchronous clock. In modern CMOS VLSI, dynamic power dissipation is governed by the charging and discharging of gate and wire capacitances:

P_{dynamic} = α · C_{load} · V_{dd}^2 · f

In high-performance GPUs and AI accelerators running at 2.5 to 3.5 GHz, billions of transistors switch billions of times every second. Even when processing sparse matrix operands or waiting for high-latency HBM3e memory fetches, the clock tree keeps toggling. Clock distribution networks—composed of massive H-trees, resonant clock buffers, and low-skew repeaters—account for 35% to 50% of an ASIC’s entire dynamic power budget before any actual math occurs.

1. The Biological Contrast: 86 Billion Neurons on 20 Watts

The human brain contains approximately 86 billion neurons and over 100 trillion synaptic connections. It performs continuous, multimodal perception, sensorimotor coordination, and online learning on an energy budget of approximately 20 Watts—less power than a dim incandescent bulb.

It achieves this extraordinary efficiency through three physical principles:

  • Extreme Activity Sparsity (α ≪ 0.001): In the cerebral cortex, fewer than 1% of neurons are active at any given millisecond. The remaining 99% sit completely silent at their resting membrane potential (-70 mV), drawing negligible metabolic energy.
  • Event-Driven Communication: Biological sensors do not transmit synchronous video frames. The human retina emits zero spikes if the visual scene is static; ganglion cells fire only when a localized contrast or illumination gradient occurs.
  • Analog Physics as Free Computation: Biology does not implement 64-bit floating-point ALUs to compute exponential decay or leaky summation. Membrane capacitance and ion channel conductances ($Na^+/K^+$ pump kinetics) perform continuous integration and decay as inherent physical properties of wet lipid bilayers.

2. Translating the Principle to Silicon (tt_um_snn_afib_detector)

In our Tiny Tapeout 09 chip, we copied this exact event-driven sparsity:

  • Between heartbeats, the LIF reservoir and feature extractors are clock-gated into deep sleep. Measured quiescent leakage is 8.4 nW.
  • When an R-peak pulse arrives, the pipeline executes for only 5 microseconds, consuming 1.88 mW of active dynamic power.
  • It instantly transitions back to sleep for the remaining 999,995 microseconds of the cardiac cycle.

The average continuous power dissipation is calculated as:

P_{avg} = [ (5 μs · 1.88 mW) + (999,995 μs · 8.4 nW) ] / 1.0 s ≈ 17.8 nW

By contrast, a conventional ARM Cortex-M0+ running an ECG classification routine at 48 MHz consumes approximately 5 mW continuous power—nearly 300,000× more energy for the exact same clinical diagnostic result.

True energy efficiency does not come from shrinking transistors to 2nm; it comes from learning when to let silicon stay quiet.

Precision-Scalable Systolic Compute: Microarchitecting the PSMAC 4×4 NPU from Gate Primitives

JULY 2026
Weight-Stationary Systolic Array · Spatial Bit-Slicing (SBB/BBU/RFU) · Per-Row Runtime Precision (INT8/4/2)

When designing neural network accelerators, the industry standard is to instantiate black-box DSP blocks provided by FPGA vendors or standard cell ASIC synthesis libraries. But black-box multipliers lock you into fixed precisions: an INT16 multiplier computing an INT4 dot product wastes 75% of its silicon area and switching energy.

In our custom NPU project (PSMAC_NPU), we designed a 4×4 weight-stationary systolic MAC array entirely from gate primitives—half-adders and full-adders—supporting per-row runtime reconfigurable INT8 / INT4 / INT2 precision.

1. Architectural Evolution: Independent Tiles (v1) → Weight-Stationary Systolic (v2)

Our initial implementation (v1) arranged 16 independent Processing Elements (PEs) in a 4×4 grid. Each tile had dedicated local SRAM ports for weights and activations, computing independent vector dot products.

While simple to verify, v1 hit an immediate architectural wall: 16 separate memory read ports consumed 16× the memory bandwidth and silicon area of a shared bus. Neighboring tiles were reading identical or shifted activation streams, yet paying the full energy penalty of SRAM wordline charging on every cycle.

In version 2, we completely re-architected the system into a 2D weight-stationary systolic mesh:

  • Weights Stationary in Mesh: Weights are broadcast row-by-row into PEs, where they latch and remain resident across hundreds of streaming cycles. Settle latency is strictly fixed at 7 cycles.
  • Activations Stream Left → Right: Activations $X$ are skewed diagonally (Row $i$ delayed by $i$ clock cycles) and propagated across horizontal registers. Every PE reuses the exact activation value its left neighbor used one cycle earlier.
  • Partial Sums Flow Top → Bottom: Accumulators flow down each column, integrating partial sums with zero external memory traffic.

2. Bottom-Up Arithmetic Hierarchy: SBB → BBU → RFU

Every multiply-accumulate operation in the NPU decomposes into a clean, gate-level spatial hierarchy: 

Gate Primitives (Half-Adders, Full-Adders, AND Gates)
       │
       ▼
Signed Bit-Block (SBB): 3-bit × 3-bit signed partial product primitive
       │
       ▼
Bit-Block Unit (BBU): 4 coupled SBBs with sign-extension logic
       │
       ▼
Reconfigurable Functional Unit (RFU): Steers INT8, dual-INT4, or quad-INT2 modes

Because precision is structural rather than an emulated software mode, switching a row from INT8 to INT4 doubles its throughput without increasing power density.

3. Per-Row Runtime Precision Scheduling

The defining breakthrough of our systolic re-architecture is per-row precision scheduling:

When weights are broadcast into the mesh, each row latches its own mode configuration tag {sx, sy, mode} simultaneously with its weight operands. Row 0 can process INT8 for a high-precision sensitive channel, while Row 3 simultaneously computes INT2 for a noise-tolerant feature map on the exact same clock cycle.

The entire design was verified across 2,588 directed, protocol, and constrained-random assertion checks, proving deterministic streaming latency ($\text{vec\_len} + 8$ cycles) with zero arithmetic overflows.
